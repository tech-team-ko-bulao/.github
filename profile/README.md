When hackathon clocks start ticking, our priority shifts to pure execution:
1. **Scope ruthlessly** — Define the core user pain point and MVP surface area.
2. **Parallelize tasks** — Split frontend UI, backend endpoints, and AI logic across members.

### `> ENGINEERING CULTURE`

We treat student projects with real-world engineering discipline:

```text
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  01. ISSUE   │ ──> │  02. BRANCH  │ ──> │    03. PR    │
│  Scoped task │     │  feature/*   │     │  Atomic diff │
└──────────────┘     └──────────────┘     └──────────────┘
                                                 │
                                                 ▼
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  06. DELETE  │ <── │  05. MERGE   │ <── │  04. REVIEW  │
│ Clean branch │     │ Protected    │     │  1 Approval  │
└──────────────┘     └──────────────┘     └──────────────┘
```

* **Zero-Secret Policy**: `.env` files and private API credentials are never committed. Templates are maintained via `.env.example`.
* **Protected Trunk**: All changes to `main` require a pull request, at least one teammate review approval, and resolved comment threads.
* **Documented Standards**: Workflows and conventions are outlined in our [`CONTRIBUTING.md`](https://github.com/tech-team-ko-bulao/.github/blob/main/CONTRIBUTING.md).
